SafeCheck AI

Aviso de privacidad

Fecha de entrada en vigor: 25 de noviembre de 2026

SafeCheck AI ayuda a revisar mensajes sospechosos y direcciones web para identificar señales comunes de estafa. Este aviso explica qué información procesa el sitio y en qué casos puede enviarse a otro servicio.

1. Mensajes de texto y correos

Cuando pegas un mensaje o correo y seleccionas Analizar señales de alerta, el verificador actual analiza ese texto en tu navegador mediante reglas integradas.

  • El texto del mensaje o correo no se envía al servidor de SafeCheck AI para este análisis local.
  • El verificador actual no guarda el mensaje que pegaste en una cuenta o base de datos de SafeCheck.
  • Evita pegar contraseñas, códigos de verificación, datos completos de tarjetas, números de identificación u otra información sensible.

2. Direcciones web y consultas de reputación

El verificador analiza en tu navegador una dirección web para buscar patrones visibles, como dominios parecidos a los oficiales, enlaces acortados y estructuras inusuales.

La consulta de reputación en tiempo real está deshabilitada actualmente. El sitio puede comunicarse con el endpoint de estado de su Worker de Cloudflare para comprobar si esa función está configurada. Esa solicitud de estado no incluye el mensaje ni la dirección web que ingresaste.

Si en el futuro se habilita la consulta de reputación, la dirección web que solicites revisar se enviará al Worker de Cloudflare de SafeCheck AI y después a Google Web Risk. No envíes enlaces privados, personales o que requieran acceso.

3. Alojamiento y proveedores de servicios

SafeCheck AI está alojado mediante GitHub Pages. El sitio también utiliza un Worker de Cloudflare para revisar la configuración de consultas y, si se habilita, realizar verificaciones de direcciones web. Estos proveedores pueden procesar información técnica, como dirección IP, datos del navegador y registros de solicitudes cuando tu navegador se conecta con sus servicios. El tratamiento de esa información se rige por sus propios avisos y condiciones.

  • Aviso de privacidad de GitHub
  • Política de privacidad de Cloudflare
  • Política de privacidad de Google

4. Cookies, analítica y publicidad

Actualmente, SafeCheck AI no instala intencionalmente cookies publicitarias, no ejecuta herramientas de analítica ni muestra publicidad personalizada. Esto podría cambiar si se agregan servicios de analítica o publicidad. Si ocurre, este aviso se actualizará para explicar los servicios y las opciones disponibles.

5. Enlaces de terceros

El sitio puede incluir enlaces a recursos externos, como CONDUSEF o PROFECO. Al abrir un enlace externo, se aplica el aviso de privacidad de ese sitio.

6. Privacidad de menores

SafeCheck AI es una herramienta informativa general y no está diseñada para recopilar información personal de menores. No envíes información privada de otras personas.

7. Cambios a este aviso

Este aviso puede actualizarse cuando cambien las funciones del sitio o sus proveedores. La fecha de entrada en vigor que aparece arriba se modificará cuando haya una actualización.

8. Contacto

Por el momento no se ha publicado una dirección específica de contacto para temas de privacidad. No envíes información personal sensible a través del sitio.
